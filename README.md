# OILPULSE — Fuel Intelligence (PWA)

เว็บแอปติดตามราคาน้ำมัน ดีไซน์ Dark Futuristic รองรับมือถือ/แท็บเล็ต/เดสก์ท็อป และติดตั้งเป็น PWA ได้

## เปิดดูในเครื่อง
เปิด `index.html` เพื่อดูหน้าตาเบื้องต้น (การติดตั้ง PWA และ Service Worker ต้องเปิดผ่าน HTTPS หรือ localhost)

## นำขึ้น GitHub Pages
1. สร้าง Repository ใหม่บน GitHub
2. แตก ZIP แล้วอัปโหลดไฟล์และโฟลเดอร์ทั้งหมดเข้า repository
3. ไปที่ **Settings → Pages**
4. เลือก **Deploy from a branch** → `main` → `/ (root)` → Save
5. รอ GitHub สร้างเว็บไซต์ แล้วเปิด URL ที่แสดงในหน้า Pages

## สถานะข้อมูลราคา — อ่านก่อนใช้งานจริง
รุ่นนี้เป็น **UI Prototype** มีตัวเลขตัวอย่างเพื่อให้ทดลองหน้าจอได้เท่านั้น ยังไม่ใช่ราคาน้ำมันสดและไม่ควรใช้ตัดสินใจเติมน้ำมัน

ระบบเตรียมจุดเชื่อมต่อ JSON feed ไว้ใน `app.js` ที่ตัวแปร `OILPULSE_FEED_URL` รูปแบบข้อมูลที่คาดหวัง:

```json
{
  "prices": [
    {"id":"g95","price":39.95,"change":0.0},
    {"id":"diesel","price":32.94,"change":0.0}
  ],
  "announcement": "ข้อความประกาศปรับราคา (ถ้ามี)"
}
```

รหัสน้ำมัน: `g95`, `g91`, `e20`, `e85`, `benzine`, `diesel`, `premium`, `premium95`

ต้องเชื่อมกับ API/แหล่งข้อมูลที่อนุญาตให้ใช้งานและตรวจสอบความถี่/เงื่อนไขการเผยแพร่ก่อนเปิดใช้จริง ไม่ควรดึงข้อมูลจากการเดาหรือใช้ตัวเลขตัวอย่างเป็นราคาปัจจุบัน

EPPO มี Open Data/API สำหรับข้อมูลด้านพลังงานและราคาปิโตรเลียมบางชุด: https://apidoc.eppo.go.th/ และ https://data.eppo.go.th/ ทั้งนี้ชุดข้อมูลราคาขายปลีกกรุงเทพฯ ในเอกสาร API เป็นข้อมูลรายเดือน จึงไม่ควรนำไปอ้างเป็นราคาหน้าปั๊มรายวันโดยตรง

## การแจ้งเตือน
- ปุ่มกระดิ่งขอสิทธิ์ Notification ของเบราว์เซอร์
- บันทึกชนิดน้ำมันที่ต้องการติดตามไว้ในอุปกรณ์
- การแจ้งเตือนเมื่อปิดเว็บ/ส่งแจ้งเตือนล่วงหน้าจริง ต้องเพิ่ม Push Notification server, subscription storage และแหล่งประกาศราคาที่มีเวลาประกาศ/เวลาเริ่มใช้ราคา
- Browser notification อย่างเดียวไม่สามารถรับประกันการแจ้งเตือนเมื่อปิดเว็บหรือเมื่อระบบปฏิบัติการหยุดการทำงานเบื้องหลัง

## ไฟล์หลัก
- `index.html` โครงสร้างหน้าเว็บ
- `styles.css` ธีมและ responsive UI
- `app.js` การแสดงราคา, การติดตาม, จุดเชื่อมต่อ feed
- `sw.js` cache/offline shell
- `manifest.webmanifest` ข้อมูล PWA
- `assets/icon.svg` ไอคอนแอป

## หมายเหตุ
ราคาน้ำมันจริงอาจแตกต่างตามผู้ให้บริการ สถานี และพื้นที่ ต้องแสดงแหล่งที่มาและเวลาที่อัปเดตทุกครั้งเมื่อเชื่อมต่อข้อมูลจริง
