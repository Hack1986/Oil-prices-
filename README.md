# OILPULSE V3 — Official-source build

## จุดที่พัฒนาจริงในรุ่นนี้
- หน้าเว็บไม่มีตัวเลขราคาสมมติแล้ว
- แสดงเฉพาะข้อมูลราคาที่ตัวดึงข้อมูลอ่านได้จากแหล่งทางการ
- มีตัวกรองแบรนด์, เวลาอัปเดต, แหล่งอ้างอิง
- GitHub Actions ตั้งรอบตรวจข้อมูลทุก 30 นาที
- เตรียมการเก็บ payload EPPO ไว้ตรวจ schema โดยไม่เดาความหมายของคอลัมน์
- ดึงราคาจากหน้า Caltex ทางการเมื่อหน้าเว็บมีรูปแบบข้อมูลที่อ่านได้

## ติดตั้ง GitHub Pages
1. สร้าง Repository และอัปโหลดทุกไฟล์จาก ZIP
2. Settings → Pages → Build and deployment → GitHub Actions
3. รัน Actions → Refresh official fuel prices → Run workflow
4. เปิดเว็บไซต์ GitHub Pages

## แหล่งข้อมูลและข้อจำกัดที่ตรวจสอบพบ
- EPPO มี API ทางการสำหรับราคาขายปลีกน้ำมันกรุงเทพฯ แบบ current/month; เอกสารระบุหน่วยบาท/ลิตรและเป็นข้อมูลรายเดือนสำหรับ endpoint เดือน
- Caltex มีหน้าแสดงราคาขายปลีกและเวลาอัปเดตบนเว็บทางการ
- Bangchak เผยแพร่เว็บเซอร์วิสสำหรับนำราคาขายปลีกไปแสดงบนเว็บแอป แต่ schema/สิทธิ์การใช้งานต้องตรวจสอบก่อนนำเข้าตัวแปลงข้อมูล
- ยังไม่มี API สาธารณะที่ยืนยันได้สำหรับ PTT และ Shell ในชุดนี้ จึงแสดงเป็นแหล่งอ้างอิง/ลิงก์ ไม่สร้างราคาปลอม
- การประกาศล่วงหน้าก่อนปรับราคายังไม่เปิดใช้ เพราะต้องมีประกาศต้นทางที่ยืนยันวันเวลาเริ่มใช้ราคา

แหล่งอ้างอิง:
- EPPO API: https://apidoc.eppo.go.th/
- EPPO Energy Data: https://www2.eppo.go.th/
- Caltex: https://www.caltex.com/th/motorists/products-and-services/fuel-prices.html
- Bangchak web service: https://www.bangchak.co.th/th/oilprice

## แจ้งเตือน
ส่วนนี้ยังเป็น permission/UI prototype เท่านั้น การแจ้งเตือนแม้ปิดเว็บต้องเพิ่ม Push service พร้อม VAPID และ backend subscription store รวมทั้งต้องมีข้อมูลประกาศที่ยืนยันได้ ห้ามนำ GitHub Pages อย่างเดียวไปอ้างว่าส่ง push notification ได้ตลอดเวลา

## สำคัญ
รอบตรวจทุก 30 นาทีไม่ได้แปลว่าราคาต้นทางอัปเดตทุก 30 นาที ระบบตรวจสอบข้อมูลใหม่ตามรอบเท่านั้น หาก parser อ่านข้อมูลไม่ได้จะแสดงไม่มีข้อมูล ไม่ใช้ราคาค้างเป็นราคาปัจจุบันโดยไม่แจ้งเตือน
